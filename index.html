second-brain

Privacy policy · last updated 21 October 2026

second-brain is a personal, single-user tool. It runs on its owner's own computer and is not offered to the public.

What it accesses

With the owner's consent, it reads the owner's Gmail through Google's API using the read-only scope (gmail.readonly). It cannot send, delete, archive or change email.

What it does with the data

  • Email is copied to a local database on the owner's computer, to search it and to write the owner a private daily summary and reminders.
  • Data is not sold, shared with third parties, or used for advertising.
  • Data is not used to train AI models.
  • The owner can delete the local copy at any time and revoke access at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
